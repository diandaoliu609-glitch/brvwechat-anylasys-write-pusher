# 账号分析与写作

## 账号画像

分析或新建一个公众号时，先明确：

- 一句话定位：为谁解决什么问题，凭什么值得关注。
- 主读者：职业/处境、已有知识、实际任务与不愿承担的风险。
- 内容边界：必写主题、可写主题、不写主题。
- 栏目：每个栏目对应稳定的读者收益、篇幅和发布节奏。
- 写作声音：专业程度、叙述视角、是否允许第一人称、常用/禁用表达。
- 合规与品牌规则：敏感表述、免责声明、引用/图片版权、互动方式。

不要从零开始堆栏目。先用真实历史稿、后台数据、留言和读者访谈判断什么值得保留；没有数据时，明确这是待验证假设。

## 选题与证据

一个可写选题至少同时满足：账号专业边界、读者的真实问题、明确的当下触发点。用下面五项筛选：信息收益、账号契合、证据强度、独特角度、可持续性。

推荐把每个选题放进以下内容原型之一：

- 政策/规则解读：原文变化、影响对象、行动清单。
- 事实核验或调查：已知问题、取证过程、结论和局限。
- 案例/企业拆解：事实证据、机制、边界和可复用启发。
- 场景经济账：假设、成本/收益、临界条件和不适用范围。
- 工具/方法：真实使用条件、步骤、结果、学习成本与失败点。
- 周报/数据窗：少量重要信号、自己的判断、下周观察点。

为每一篇建立事实卡。需要时效核验时，用权威网页或原始文件而非二手转述。文章至少标明来源与更新时间；涉及结论性数据，说明统计口径。

## 成稿与标题

先写结论，再写标题。标题按准确、具体、读者收益、信息差、正文一致性各 20 分评分；低于 80 分不推荐。

正文的通用骨架是：具体问题或场景 → 可核验事实 → 分析与判断 → 对目标读者的影响 → 下一步怎么做/继续观察什么。叙事或体验类文章可用真实过程推进，但不能把虚构细节当真实经历。

避免“随着……发展”“值得注意的是”“综上所述”等没有信息的连接句。段落宜短，长短句交替；小标题、列表和强调只服务于手机阅读，不要把正文变成提纲。

## 发布前检查

- 标题、摘要和封面承诺的内容，正文都有回答。
- 关键数字、时间、引语、政策或业务状态有原始出处。
- 观点、假设、预测与事实有清晰边界。
- 没有收益承诺、绝对化措辞、误导性对比或未授权素材。
- 版式在手机端可读：单屏重点明确、宽表已改卡片/拆分、图有图注和版权来源。
- 文末含数据来源、更新时间，以及按行业需要的免责声明。
