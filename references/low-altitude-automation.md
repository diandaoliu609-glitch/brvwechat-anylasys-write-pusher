# 低空智瞰自动化

## 单次运行

1. 根据星期选择栏目：周一政策雷达；周三工程实战，在三维采集/解算、相机视觉、开源算法、工程工作流间轮换；周五按自然周序号在企业与案例、产品观察、一周低空情报间轮换。其他日期除非有重大政策，不生成草稿。
2. 检查最近 30 天本地清单与草稿标题，避免同一事件换标题重复生产。
3. 先检索 A 级来源，再用行业媒体或公众号寻找线索。关键断言必须回到政府、监管、交易平台、上市公司公告或企业法定/官方材料。
4. 保存文章清单 JSON，字段至少包括 `account`、`column`、`title`、`digest`、`text`、`html`、`sources`、`issues`。每个 source 包含 `title`、`url`、`tier`、`date`。
5. 文章写作遵循低空智瞰运营手册；技术、企业、产品和案例稿还须遵循 `low-altitude-engineering.md`。禁止把“规划、意向、签约、试点、订单、交付、收入”混写。
6. 用稳定主题排版：政策雷达 `chinese`，深度稿 `focus-blue`，周报 `data-report`。正文 HTML 需包含 `<div id="article">`。
7. 运行：

   ```bash
   python3 scripts/validate_article.py /absolute/path/manifest.json
   ```

8. 只有返回 `VALIDATION_OK` 才能推送草稿。推送后把日期、栏目、标题、来源和 `media_id` 追加到本地运行记录。

## 质量门槛

- 政策雷达：1200–2200 汉字，至少 2 个 A 级来源。
- 智瞰深一度：1500–2600 汉字，至少 2 个 A/B 级独立来源，至少一个可复核数据或原始案例。
- 工程实战：1600–2800 汉字，至少 3 个来源，其中包含原始仓库/论文/数据集及一个独立来源；必须写复现条件、参数边界、适用场景、失效条件和开源许可。
- 企业与案例：1500–2400 汉字，至少 3 个来源；必须区分企业自述、合同/招采/公告证据和第三方验证，并标项目阶段。
- 产品观察：1400–2200 汉字，至少 3 个来源；参数必须附测试条件或口径，并写适用场景、限制条件和替代方案。
- 一周低空情报：900–1600 汉字，至少 3 个来源，其中至少 2 个 A/B 级来源。
- 标题不超过 64 个 UTF-8 字节，摘要不超过 120 个汉字。
- 文章必须含来源、更新时间、下一步观察点和免责声明。
- 命中合规问题、来源不足、HTML 缺正文容器或存在未解决 `issues` 时停止。

## 推送链路

首选微信白名单出口。当前执行环境不在白名单时，可通过用户已配置的远程中继上传 HTML、封面和最小推送脚本；中继地址、用户名和密钥必须通过外部私有配置或 SSH config 提供，不得写入 skill。远端凭据文件权限必须为 600。中继不可用时保留本地待推包并通知用户，不要反复创建重复草稿。

正式群发永远不属于本自动化；草稿进入后台后由人工手机预览、核对链接与排版，再决定是否发布。
