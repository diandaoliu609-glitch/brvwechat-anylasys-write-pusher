# brvwechat-anylasys-write-pusher

一个面向微信公众号内容运营的 Codex skill，用于账号分析、选题、证据核验、写作、排版和安全推送草稿箱。

## 安装

将本仓库目录复制到 Codex skills 目录，并确保入口文件位于：

```text
~/.codex/skills/brvwechat-anylasys-write-pusher/SKILL.md
```

账号凭据必须保存在 skill 目录之外，并限制为仅当前用户可读。仓库只包含空白配置示例，不包含任何真实凭据、服务器地址或账号密钥。

## 安全边界

- 只自动推送到草稿箱，不自动正式群发。
- 关键事实需来源核验，未通过质检不得推送。
- 凭据通过外部私有配置读取，不进入命令、日志、文章或 Git。
- 白名单出口或中继不可用时保留待推包，不绕过安全控制。
